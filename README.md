# Practica-4-PDS-Electromyographic-signals-EMG

ITEMS
1 Se muestra la gráfica de la señal capturada con todas sus características, incluyendo frecuencia de muestreo, tiempo de muestreo, longitud de la señal, cantidad de contracciones, músculo medido.
2 El filtro es diseñado de acuerdo con parámetros vistos en clase. Se sustenta con cálculos el órden del filtro y la o las frecuencias de corte, tamaño de riple, tipo de filtro, entre otros.
3 Se aplica una ventana y se explica el criterio utilizado para seleccionar el tipo. Se describe la ventana en cuanto a tamaño y forma y se muestra la ventana comparandola con la señal, tanto antes como después de la convolución.
4 Se muestra una transformada al dominio de la frecuencia para cada contracción, describiendo sus partes, como frecuencia dominante, frecuencia media, desviación estándar.
5 Se analizan e interpretan los resultados a partir de herramientas estadísticas como el test de medias, formulando correctamente las hipótesis nula y alternativa y llegando a una conclusión sobre el cambio observado en la media de la frecuencia.
